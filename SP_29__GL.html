Для вирішення такого завдання логічним припущенням є пошук варіанту із найменшими відхиленнями. Англійською мовою відхилення будуть вимовлятися як residual errors. Одним із таких методів є метод найменших квадратів.

Метод найменших квадратів¶

Суть методу полягає у мінімізації суми квадратів різниці між розрахованим значенням лінійної регресії та виміряним значенням. Вибір квадратів пов'язано із зручністю підрахунку для від'ємних та додатних відхиленнях. Рівняння прямої має наступний вигляд:

$$ \hat{y} = \beta_1 x + \beta_0 $$

  • $ \beta_1 $ - відповідає за нахил лінії,
  • $ \beta_0 $ - перетин лінії з віссю ординат (bias - упередження).

Щоб обчислити значення коефіцієнтів $\beta_0$ та $\beta_1$ застосуємо метод найменших квадратів

$$ \hat{y}=\beta_1 x + \beta_0 $$

$$ \beta_1 = \frac{\displaystyle\sum_{i=0}^n (x_i-\tilde{x})(y_i-\tilde{y})}{\displaystyle\sum_{i=0}^n (x_i-\tilde{x})^2}$$

$$ \beta_0 = \hat{y}-\beta_1 \tilde{x} $$

  1. Знаходження середніх значень для змінних $\tilde{x}$ та $ \tilde{y}$.

  4. Знаходження коефіцієнтів $\beta_0$ та $\beta_1$.

Навчальне питання 2. Лінійна регресія. Функція вартості¶

Теорія - 20 хв, практика - 20 хв

Розглянутий вище приклад дозволяє знайти вираз для знаходження значень цільової змінної, що має лінійну залежність від однієї вхідної величини (ознаки). При залежності значень цільової змінної від декількох ознак застосовується інший підхід, який базується на функції вартості. При цьому лінійні функції будуються для кожної ознаки. Загальний вираз для функції вартості має наступний вигляд

$$ J(\beta) = \displaystyle\sum_{i=0}^n \beta_i x_i $$

Оскільки, ми маємо знайти залежність, яка дає найменші похибки для усіх ознак, то по суті ми знаходимо мінімуми для кожної із лінійних функцій. Ці мінімуми зручно трансформувати у квадратах різниці між значеннями відхилень цільової змінної. Запис такої ідеї здійснюється наступним чином

$$ J(\beta) = \frac{1}{2m}\displaystyle\sum_{j=0}^m (y^j-\tilde{y}^j)^2 $$

m - кількість ознак; 2 - для зручності подальших розрахунків

Значення $ \tilde{y} $ для кожної ознаки визначається на основі полінома

$$ \tilde{y}=\displaystyle\sum_{i=0}^n \beta_i x_i $$

Виходячи із цього загальний вираз матиме вигляд:

$$ J(\beta) = \frac{1}{2m}\displaystyle\sum_{j=0}^m (y^j-\displaystyle\sum_{i=0}^n \beta_i x_i^j)^2 $$

Взявши похідну вираз для мінімізації функції матиме вигляд

$$ J(\beta) = \frac{1}{m}\displaystyle\sum_{j=0}^m (y^j-\displaystyle\sum_{i=0}^n \beta_i x_i^j)(-x_k^j) $$

Таке рівняння не має аналітичного рішення. У такому випадку застосовують числові методи, наприклад градієнтний метод спуску.

Для прикладу розглянемо набір даних, який характеризує залежність між витратами на підготовку матеріалів для розповсюдження через телебачення, радіо, соціальні мережі та ефект, що отримується.
