НАВЧАЛЬНІ ПИТАННЯ

1. Квантування кольорів

Теорія - 20 хв, практика - 0 хв

Розділ машинного навчання без учителя дозволяє вирішувати широкий спектр завдань. В основному такі завдання пов'язані із пошуком закономірностей у даних. Серед таких завдань є і пов'язані із обробкою зображень - квантування кольорів.
Зображення зберігається у пам'яті цифрового пристрою як матриця, що описує кожен піксель - його координату та колір.

  • координати (у площині) - порядок знаходження елементу у матриці
  • колір для кожного пікселя:
    • для монохромних - шкала від білого до чорного;
    • для кольорових - варіації щодо змішування основних кольорів, наприклад RGB. При цьому вже зберігається 3 матриці із зображенням у червоному, зеленому та синьому кольорі

Рис. 1.1

При цьому дані про файл є тривимірними. Для роботи із ними, використовуючи бібліотеку **pandas**, необхідно перетворити ці дані у двовимірний масив. Масив буде містити об'єкти із трьома ознаками - інтенсивність базових кольорів у кожному пікселі

Рис. 1.2

Інтенсивність / насиченість кольору для пікселя у зображенні, як правило задається числом від 0 до 255. При цьому нуль - найтемніший, 255 - найсвітліший
pixel red green blue
1 244 12 17
2 236 19 22
... ... ... ...
n 145 201 70

Таким чином, отриманий масив, стає придатним для використання бібліотеками для машинного навчання.
Використовуючи метод k-means можна знайти у зображенні близькі один до одного кольори.
Близькі один до одного кольори - коли значення базових кольорів не виходять за межі певного діапазону.

Рис. 1.3

Використання методу k-means передбачає вибір та визначення кількості кольорів для початку його роботи. У контексті цього завдання, кількість кластерів - це кількість кольорів у якому буде представлено зображення після обробки.
За результатами обробки для кожного рядка (пікселя) буде отримано номер кластеру до якого він відноситься.
Розглянемо не практиці здійснення квантування кольорів у зображеннях.

# KMeans clustering
from sklearn.cluster import KMeans

# Define the model
# Setting n_clusters=7 - numbers of colors to extract
model = KMeans(n_clusters=4)
