Важливим етапом будь-якого дослідження є попередній аналіз. Це дозволяє вірно визначити подальші дії та й взагалі стратегію роботи з даними. Для прикладу, розглянемо вибірку з коментарями про кандидата на виборну посаду та уже проведеної обробки з віднесенням до тематики, та емоційною оцінкою.

Вибірку такого типу називають - розмічені дані. Розмічені дані, в залежності від інструменту, який застосовувався, можуть зберігатися у різних форматах. Одні із них можуть бути одразу прочитані та завантажені у датафрейм, інші - потребують підготовки.

Застосовуючи підхід запропонований на попередньому занятті, проведемо аналіз наданих даних.

# Підготовка даних для класифікації текстових повідомлень

import re
from pprint import pprint

data = []
with open('data_president.txt', 'r', encoding='utf-8') as f:
    obj = {'text': '', 'sentiment': '', 'theme': ''}
    for line in f.readlines():
        if re.match(r'^\d{1,2}. Текст: ', line):
            txt = re.match(r'^\d{1,2}. Текст: "(.*)"', line)
            obj['text'] = txt.group(1)
        elif re.match(r'^Розмітка: {', line.strip()):
            match_markup = re.match(r'^Розмітка: {.*"настрій": "(.*)", "тема": "(.*)"}', line.strip())
            if match_markup:
                sentiment = match_markup.group(1)
                theme = match_markup.group(2)
                obj['sentiment'] = sentiment
                obj['theme'] = theme
                data.append(obj)
                obj = {'text': '', 'sentiment': '', 'theme': ''}
