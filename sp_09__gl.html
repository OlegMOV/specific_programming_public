1. Основи науки про дані

Теорія - 10 хв, практика - 0 хв

У сучасному світі дані часто називають «новою нафтою». Проте, як і сира нафта, самі по собі вони мають обмежену цінність. Справжня потужність з’являється тоді, коли дані зібрані, структуровані та перетворені на набори даних (Datasets).

🎯Набір даних — це впорядкована колекція інформації, яка зазвичай представлена у табличному вигляді.

У такому форматі кожен рядок відповідає окремому об'єкту (спостереженню), а кожен стовпець — конкретній характеристиці (атрибуту) цього об'єкта.

Набори даних можуть бути:

  • Структурованими: Чіткі таблиці (CSV, Excel, SQL-бази).
  • Напівструктурованими: Мають певну ієрархію, але не жорстку форму (JSON, XML).
  • Неструктурованими: Тексти, зображення, аудіо та відео (найскладніші для автоматичного аналізу).

Такі дані використовуються у кожній сфері, де потрібно приймати рішення не «наосліп», а на основі фактів:

  1. Бізнес та фінанси: Прогнозування прибутків, аналіз ризиків кредитування, виявлення шахрайських транзакцій.
  2. Наука та медицина: Аналіз результатів клінічних досліджень, розробка нових ліків, моделювання кліматичних змін.
  3. Маркетинг: Сегментація клієнтів, персоналізація реклами (саме тому ви бачите оголошення товарів, які щойно шукали).
  4. Державне управління: Оптимізація міського трафіку, планування бюджетів, аналіз демографічних показників.
  5. Військова справа: Прийняття рішення при плануванні бойових / спеціальних дій.

Робота з наборами даних зазвичай зводиться до кількох типових завдань:

1. Очищення даних (Data Cleaning)

Це «брудна», але найважливіша робота. Дані з реального світу рідко бувають ідеальними.

  • Завдання: Видалити дублікати, виправити помилки в іменах, заповнити пропуски ().
  • Кейс: Компанія має список клієнтів, де в деяких записах пропущено номер телефону. Аналітик має вирішити: видалити ці записи чи заповнити їх значенням "Unknown".
2. Розвідувальний аналіз (EDA — Exploratory Data Analysis)

Пошук закономірностей та аномалій до того, як застосовувати складні алгоритми.

  • Завдання: Розрахувати середні значення, знайти кореляції між показниками, візуалізувати розподіл.
  • Кейс: Магазин аналізує дані за рік і помічає, що продажі парасольок корелюють не лише з дощем, а й з початком осіннього сезону знижок.
3. Прогнозування (Predictive Analytics)

Створення моделей, які на основі минулого передбачають майбутнє.

  • Завдання: Використати історичні дані для тренування моделі машинного навчання.
  • Кейс: Банк аналізує набір даних про попередні кредити, щоб передбачити, чи поверне новий клієнт позику вчасно.
4. Агрегація та звітність

Перетворення тисяч рядків у зрозумілі цифри для керівництва.

  • Завдання: Згрупувати дані за певним критерієм.
  • Кейс: Університет аналізує результати сесії, щоб вирахувати середній бал по кожному факультету окремо.

Таким чином, із застосуванням інформаційних технологій, інформаційні потреби можливо задовольнити двома шляхами:

  • у одному випадку достатньо візуалізувати наявні дані;
  • застосовувати інструменти для обробки даних. Наприклад методи машинного навчання (machine learning).
Машинне навчання особливо актуальне коли взаємозв'язки між даними не очевидні, або такі що потребують врахування багатьох критеріїв.

Розглянемо як можливо почати виконання таких завдань із метою подальшого втілення у життя їх результатів. Як правило, цей процес має наступні кроки

Рис. 1.2

Першим кроком - виконання є вияснення способу отримання усіх можливих даних, що на пряму чи опосередковано дають уявлення та описують процес чи явище, яке досліджується.
Другий крок - попередня обробка даних, з наступним третім кроком, що передбачає збереження даних. Для цього можуть використовуватися локальні файли (.xlsx, .csv, .db, .json), так і хмарні сервіси для збереження інформації.

Ці перші три кроки називають у науці про дані - Data engineering.

Четвертим кроком є очищення (первинна) обробка даних, що вміщує у собі структурування. Окремим завданням є вирішення, яким чином будуть враховані дані, які тимчасово відсутні або були втрачені (прогалини даних).
П'ятим кроком - є аналіз даних (Exploratory Data Analysis - EDA). На цьому кроці передбачений статистичний аналіз, а також візуалізація, що дозволяє осягнути аналітику про можливі закони розподілу величин.

Четвертий та п'ятий крок називають Data Analysis.

Отже по виконанню п'ятого кроку, у випадку якщо завданням є дати відповідь на поставлене питання, є можливість створити звіт / доповідь, візуалізувати дані та оформити у вигляді презентації. І у подальшому надати їх посадовій особі, або іншим аналітикам для узагальнення.

У випадку необхідності створення інструменту щодо попереднього трансформування даних, постає питання у створенні моделей машинного навчання. Ці моделі є частиною програмного додатку, що приводить дані до вигляду придатного для аналізу. І це є шостим кроком.

У загальному моделі машинного навчання можна розділити на дів великі групи

Рис. 1.3

При застосуванні Supervised Learning, як правило, вирішують завдання, що передбачають прогнозування розвитку процесу, що досліджується. У випадку Unsupervised Learning, як правило, здійснюється пошук закономірностей, взаємозв'язків між подіями.  

П'ятий та шостий крок називають Machine Learning.

Отримані моделі машинного навчання є частиною кінцевого продукту, наприклад сервіс для певного програмного продукту, який функціонує на основі потоку даних.

Такі продукти використовують для прийняття рішення на основі даних, прогнозування розвитку подій чи ситуацій, що склалися, моделювати варіанти вирішення певних завдань.

На кожному із описаних кроків є можливість використання бібліотек Python, що суттєво спрощує такі, здавалося б, достатньо складні завдання.

2. Робота з набором даних за допомогою об'єкту Series

Теорія - 10 хв, практика - 30 хв

Pandas — це високорівнева бібліотека Python для аналізу даних, побудована на базі NumPy. Вона надає зручні структури даних для роботи з таблицями (фреймами) та часовими рядами.

🔑 Основні переваги:
  • Ефективна робота з великими наборами даних у пам'яті.
  • Інструменти для читання/запису даних (CSV, Excel, SQL, JSON).
  • Вбудована обробка пропущених значень ().
  • Можливість змінювати форму набору даних (pivoting, reshaping).

У Pandas виділяють два ключові об'єкти:

  • Series одномірний масив з мітками (індексами). Можна уявити як один стовпець таблиці.
🧩 Приклад
import pandas as pd
s = pd.Series([10, 20, 30], index=['a', 'b', 'c'])
  • DataFrame двомірна структура даних, що нагадує таблицю SQL або аркуш Excel. Складається зі стовпців, кожен з яких є об'єктом Series.

Для роботи з одномірними даними в бібліотеці Pandas є відповідний об'єкт - Series.

При використанні даного об'єкта для доступу до його елементів є можливість використання числового індексу рядка, а також і іменовані індекси.

  1. .loc — доступ за міткою (назвою рядка/стовпця).
  2. .iloc — доступ за цілочисельним індексом (позицією).

.loc є більш зручним, оскільки числовий індекс більш складний для запам'ятовування.

Створити об'єкт Series можна на основі масивів NumPy, а також списків Python.

🧩 Приклад
import numpy as np
import pandas as pd

arr_p = [1994, 2014, 2022]
arr_np = np.array(arr_p)
print(arr_p)
print(arr_np)

[1994, 2014, 2022] 
[1994 2014 2022]
🧩 Приклад
data = pd.Series(arr_p)
print(data)

0 1994 
1 2014 
2 2022 
dtype: int64

Як видно з попереднього прикладу кожен новий рядок має свій числовий індекс. Для зміни такого індексу на іменований необхідно створити за кількістю рядків список найменувань, та додати другим аргументом при створені екземпляру об'єкта Series.

🧩 Приклад
name_indexes = ['independent', 'start war', 'increased war']
data = pd.Series(arr_p, name_indexes)
print(data)

	independent 1994 
	start war 2014 
	increased war 2022 
	dtype: int64

Таким чином, є можливість додати іменовані індекси до масиву. Щоб переглянути значення об'єкту Series можна застосовувати обидва індекси

🧩 Приклад
data['independent']

np.int64(1994)

data.iloc[1]

np.int64(2014)

Використання іменованого індексу збільшує читабельність коду. Але при цьому слід зауважити, що назву індексу треба записувати враховуючи регістр та наявність пробільних символів.

Для того щоб подивитися, які є індекси в об'єкті Series, використовують метод .keys()

🧩 Приклад
data.keys()

Index(['independent', 'start war', 'increased war'], dtype='object')

Створення об'єкту Series можливе і на основі словника. Це одразу вирішує питання щодо створення іменованого індексу, оскільки ним автоматично стають ключі словника.

🧩 Приклад
dict_lp = {
'JavaScript': 15.4,
'TypeScript': 15.1,
'Python': 14.7,
'Java': 12.7,
'C#': 12.7}
arr_lp = pd.Series(dict_lp)
arr_lp

JavaScript 15.4 
TypeScript 15.1 
Python 14.7 
Java 12.7 
C# 12.7 dtype: float64

Series є об'єктом, який базується на основі масиву бібліотеки NumPy, а тому може використовуватися broadcasting - виконання одночасних дій над усіма/визначеними елементами масиву. Тобто є можливість змінювати усі елементи масиву одночасно використавши математичні операції, наприклад:

🧩 Приклад
data - 100

independent 1894 
start war 1914 
increased war 1922 
dtype: int64

Розглянемо як можуть взаємодіяти між собою два об'єкти Series. Для прикладу, є результати стрільб для 5 осіб за два дні, причому не всі особи були присутні у першому і другому дні.

🧩 Приклад
arr_1 = {'sold_1': 22, 'sold_2': 20,'sold_3': 18, 'sold_4': 25}
arr_2 = {'sold_1': 20, 'sold_2': 23,'sold_3': 19, 'sold_5': 24}

res_1 = pd.Series(arr_1)
res_2 = pd.Series(arr_2)
print(res_1, f'{'-'*16}', res_2, sep='\n')

sold_1 22 
sold_2 20 
sold_3 18 
sold_4 25 
dtype: int64 
---------------- 
sold_1 20 
sold_2 23 
sold_3 19 
sold_5 24

Для того щоб оцінити результативність особового складу розрахуємо для кожного відсоток попадання від максимально можливого за один день. При розрахунку враховувалося, що максимально можлива кількість балів - 30.

🧩 Приклад
res_1 * 100 / 30

sold_1 73.333333 
sold_2 66.666667 
sold_3 60.000000

dtype: float64

Таким чином, таке завдання можна обчислити в одну дію.

Розглянемо як можуть взаємодіяти між собою два об'єкти. Для цього знайдемо суму балів стрільб за два дні.

🧩 Приклад

sold_1 42.0 
sold_2 43.0

Як видно із прикладу, відсутні індекси призвели до виведення значення добутку рівному NaN (not a number). Оскільки не вказано значення за-замовчуванням для такого випадку.

Для оголошення значення за-замовчуванням для відсутніх елементів масивів необхідно застосовувати відповідні методи екземплярів класу Series.

🧩 Приклад
res_1.add(res_2, fill_value=0)

sold_1 42.0 
sold_2 43.0 
sold_3 37.0 
sold_4 25.0 
sold_5 24.0 
dtype: float64

Для того щоб знайти середнє значення у стовпці (об'єкті Series) або у конкретному стовпці DataFrame, у Pandas використовується метод .mean().

🧩 Приклад
import pandas as pd

# Створюємо Series
s = pd.Series([10, 20, 30, 40, 50])

# Знаходимо середнє
avg = s.mean()
print(f"Середнє значення: {avg}") # Виведе 30.0

Робота з часовими рядами — це одна з найсильніших сторін Pandas. Бібліотека пропонує спеціальний тип даних datetime64, який дозволяє проводити складні обчислення з часом так само легко, як і з числами.

Найчастіше при завантаженні з CSV дати сприймаються як звичайний текст (object). Перший крок — перетворення за допомогою pd.to_datetime().
Що у подальшому дозволяє працювати із датою як із об'єктом:

🧩 Приклад
import pandas as pd
# Стовпець із датами у вигляді рядків
series = pd.Series(['2026-01-01', '2026-02-15', '2026-03-21'])

# Перетворення
date_series = pd.to_datetime(series)
print(date_series)

# Змінені дати
new_series = date_series + pd.Timedelta(days=7)
print(new_series)

0   2026-01-01
1   2026-02-15
2   2026-03-21
dtype: datetime64[us]
0   2026-01-08
1   2026-02-22
2   2026-03-28
dtype: datetime64[us]
Після перетворення з'являється доступ до аксесора .dt, який дозволяє "витягувати" будь-яку частину дати.

Робота з текстом у Pandas реалізована через спеціальний аксесор .str. Він дозволяє застосовувати рядкові методи Python (такі як upper(), split(), replace()) відразу до всього стовпця.

Ці операції найчастіше використовуються для стандартизації даних перед аналізом (наприклад, щоб "Київ" та "київ" сприймалися як одне значення).

Метод Опис Приклад
.str.lower() / .upper() Зміна регістру df['City'].str.capitalize()
.str.strip() Видалення пробілів на початку й у кінці df['Name'].str.strip()
.str.replace() Заміна підрядка df['Phone'].str.replace('-', '')
.str.len() Підрахунок кількості символів df['Comment'].str.len()
🧩 Приклад
import pandas as pd

series = pd.Series(['AbcDe', 'ifGj', 'ZXsER'])
print(series.str.lower())

0    abcde
1     ifgj
2    zxser
dtype: str

Таким чином, series є потужним інструментом для роботи із даними.

2.2. Вивчення даних завантажених із файлу

Перед початком роботи з даними, які були завантажені із файлу необхідно з ними ознайомитися. Це дозволить:

  • по-перше переконатися, що дані були завантажені коректно,
  • по-друге - що це дійсно ті дані, які ми очікували,
  • по-третє - вивчити їх структуру, та одиниці розмірності їх значень.

Для перегляду стовпців, наявності для них іменованих чи числових індексів, використовують атрибут .columns

df.columns

Для перегляду кількості та індексу рядків у завантажених даних використовують атрибут .index

df.index

Для ознайомлення із даними використовується метод .head(), який за-замовчуванням виводить перших 5 рядків даних. При необхідності кількість рядків, які потрібно вивести, можна вказати як аргумент методу

df.head() # .head(8)

Якщо необхідно переглянути останні рядки використовують метод .tail()

df.tail()

Для наявних у даних стовпців з числовими даними є можливість проглянути їх статистику, а саме:

  • count - чисельність значень у стовпці, без врахування відсутніх значень;
  • mean - середнє значення у стовпці;
  • sid - середньоквадратичне відхилення;
  • min - мінімальне значення;
  • 25%,50%,75% - квантилі, що вказують на розподіл значень від мінімального до максимального (наприклад: 25% - значить, що серед усіх значень, таких які менше вказаного числа - 25%);
  • max - максимальне значення.

Для отримання таких даних необхідно викликати метод .describe()

2.3. Робота зі стовпцями екземпляра об'єкта DataFrame

Для отримання доступу до окремих стовпців необхідно до змінної, що вказує на екземпляр об'єкта DataFrame додати квадратні дужки в яких вказати назву стовпця. Оскільки назви стовпців можуть бути із декількох слів то назву вказують у лапках. При цьому доцільно почати писати назву та натиснути tab для підказки, щоб не зробити помилок у назві.

df['total_bill']

Іноді необхідно працювати із вибіркою стовпців, для цього необхідно створити список стовпців та помістити його у квадратні дужки після змінної

df[['total_bill', 'tip']]
# УВАГА: подвійні квадратні дужки

За необхідності можна створити стовпець, який є результатом математичних операцій над кількома колонками. Для прикладу можна порахувати, який відсоток мають елементи одного стовпця відносно іншого

df['tip'] * 100 / df['total_bill']

Принцип додавання нового стовпця до екземпляру об'єкта DataFrame як і в словнику Python. Для цього записується назва нового стовпця у квадратні дужки та присвоюється значення, як результат математичних дій

df['tip_persnt'] = df['tip'] * 100 / df['total_bill']

Інколи математичні операції приводять до значень чисел з багатьма знаками після коми, які нам не потрібні. Для усунення цього можна застосовувати операції закруглення чисел.

df['tip_persnt'] = np.round(df['tip'] * 100 / df['total_bill'],2)

Для цього використовується функція з бібліотеки numpy, де першим аргументом є математичне визначення broadcasting операції, а другим - бажана кількість знаків після крапки.

Для видалення даних з екземпляру об'єкта DataFrame використовують метод .drop().
Даний метод містить ряд аргументів:

  • labels - список індексів, які необхідно видалити;
  • axis - два значення 0 - для рядків, 1 - для стовпців, які визначені у аргументі labels (за-замовчуванням - 0);
  • index - список індексів рядків, (labels, axis=0 is equivalent to index=labels);
  • columns - список індексів стовпців, (labels, axis=1 is equivalent to columns=labels);
  • inplace - аргумент, який відповідає за внесення змін у вихідний набір даних. Для цього потрібно виставити значення True, за-замовчуванням - False.
df.drop('tip_persnt', axis=1)
Слід зауважити, що даний метод не вносить зміни у екземпляр набору даних, а повертає новий набір. Цей набір можна використовувати у подальшому для обчислень зберігши у окрему змінну.

Для зміни поведінки - змінити аргумент inplace на True.

Для доступу до рядків застосовують наступні способи:

  • .iloc() - аргументом вказується числовий індекс;
  • .loc() - аргументом вказується іменований індекс.

Якщо необхідно отримати кілька рядків, тоді застосовують зрізи для числових індексів .iloc[1:6], і список .loc[[col_1, col_2]] для іменованих індексів.

Для зміни поведінки - змінити аргумент inplace на True.

2.4. Робота з рядками екземпляра об'єкта DataFrame

За-замовчуванням для набору даних кожному рядку автоматично присвоюється індекс, який є числовим і починається з нуля та закінчується значенням кількості рядків мінус один.
Для більшості випадків цього достатньо для роботи, але бувають випадки коли необхідно мати унікальні значення для кожного рядка. Наприклад, коли розділяємо набір даних на кілька частин, у зв'язку із їх чисельністю. Оскільки у кожній такій частині будуть однакові індекси рядків 0,1, 2 ... Для цього у об'єкта DataFrame є метод який дозволяє визначити будь-який стовпець індексом, наприклад

При виведенні екземпляра об'єкта DataFrame заголовок таблиці буде мати вже два рівня:

  • перший - назви стовпців (іменовані індекси стовпців);
  • другий - назва індексу.

У подальшому значення індексів рядків виділяються шрифтом.

Така команда виконується лише один раз для конкретного екземпляру. Вдруге призначення такого індексу буде супроводжуватися помилкою - такий стовпець не знайдено.
За-замовчуванням цей метод не вносить зміни у набір даних. Для зміни такої поведінки можна перепризначити змінну

df.set_index('Payment ID')

Така операція має зворотню дію. Для цього необхідно використати метод .reset_index(), що поверне числовий індекс, а призначений індекс знову стане стовпцем.

Для доступу до рядків застосовують наступні способи:

  • .iloc() - аргументом вказується числовий індекс;
  • .loc() - аргументом вказується іменований індекс.

Якщо необхідно отримати кілька рядків, тоді застосовують зрізи для числових індексів .iloc[1:6], і список .loc[[col_1, col_2]] для іменованих індексів.
