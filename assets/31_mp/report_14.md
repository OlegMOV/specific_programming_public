# Масштабування даних та його вплив на K-Means

## Вступ

У машинному навчанні перед обробкою даних часто необхідно привести числові ознаки до спільного масштабу. Цей процес називається **масштабуванням даних**.

Наприклад, у наборі даних можуть бути вік людини та її дохід. Вік вимірюється десятками років, а дохід — десятками тисяч гривень. Через це деякі алгоритми можуть надавати перевагу ознаці з більшими числовими значеннями.

Існують два поширені методи масштабування:

- нормалізація;
- стандартизація.

## Основні методи масштабування

### Нормалізація Min-Max

Нормалізація перетворює значення ознаки до певного діапазону, найчастіше від 0 до 1.

Формула:


$$x' = (x - x_{min}) / (x_{max} - x_{min})$$


де:

- $x$ — початкове значення;
- $x_{min}$ — мінімальне значення ознаки;
- $x_{max}$ — максимальне значення ознаки;
- $x`$ — нове масштабоване значення.

Після нормалізації мінімальне значення стає 0, максимальне — 1, а всі інші значення розташовуються між ними.

**Перевага:** усі значення приводяться до спільного діапазону.

**Недолік:** метод чутливий до викидів — надзвичайно великих або малих значень.

### Стандартизація Z-score

Стандартизація перетворює дані так, щоб середнє значення ознаки дорівнювало приблизно нулю, а стандартне відхилення — одиниці.

Формула:

$$z = (x - μ) / σ$$

де:

- `x` — початкове значення;
- `μ` — середнє значення ознаки;
- `σ` — стандартне відхилення;
- `z` — стандартизоване значення.

Після стандартизації дані центруються навколо нуля. Значення, більші за середнє, стають додатними, а менші за середнє — від’ємними.

**Перевага:** ознаки з різними одиницями вимірювання стають порівнюваними.

**Недолік:** метод також чутливий до викидів.

### Порівняння методів

| Критерій | Нормалізація | Стандартизація |
|---|---|---|
| Назва методу | Min-Max | Z-score |
| Діапазон значень | Зазвичай від 0 до 1 | Необмежений |
| Орієнтація | Мінімальне та максимальне значення | Середнє значення та стандартне відхилення |
| Чутливість до викидів | Висока | Висока |
| Коли використовувати | Коли потрібен конкретний діапазон | Для масштабування ознак відносно середнього |

## Приклад на Python

Для масштабування даних у Python використовують бібліотеку `scikit-learn`.

```python
from sklearn.preprocessing import MinMaxScaler, StandardScaler

# Початкові дані
X = [
    [10000],[20]
    [30000],[30]
    [50000],[40]
    [70000][50]
]

# Нормалізація
minmax = MinMaxScaler()
X_normalized = minmax.fit_transform(X)

# Стандартизація
standard = StandardScaler()
X_standardized = standard.fit_transform(X)

print("Нормалізація:")
print(X_normalized)

print("Стандартизація:")
print(X_standardized)
```

Метод `fit_transform()` визначає параметри масштабування та одразу перетворює дані.

- `MinMaxScaler()` виконує нормалізацію даних.
- `StandardScaler()` виконує стандартизацію даних.
- `fit()` вивчає параметри даних.
- `transform()` застосовує перетворення.
- `fit_transform()` виконує обидві дії одночасно.

## Як масштабування впливає на K-Means

**K-Means** — це алгоритм машинного навчання, який розподіляє об’єкти на групи, або кластери, за їхньою схожістю.

Для визначення схожості він використовує **евклідову відстань** — відстань між точками у просторі ознак.

Формула:

```text
d(A, B) = √((A₁ - B₁)² + (A₂ - B₂)² + ... + (Aₙ - Bₙ)²)
```

Уявімо, що потрібно розділити клієнтів на групи за віком і доходом. Вік може становити 20–60 років, а дохід — 10 000–100 000 гривень.

Без масштабування дохід може значно сильніше впливати на обчислення відстані, ніж вік. У результаті алгоритм переважно групуватиме клієнтів за доходом, а ознака віку майже не братиме участі у формуванні кластерів.

Після масштабування обидві ознаки приводяться до порівнюваного масштабу. Тому кожна з них може краще враховуватися під час кластеризації.

**Важливо:** без масштабування K-Means може створити кластери, які не відображатимуть усі важливі характеристики даних.

Однак масштабування не гарантує ідеального результату. Вибір методу залежить від особливостей даних, наявності викидів і поставленого завдання.

## Висновки

Нормалізація та стандартизація допомагають підготувати дані до машинного навчання.

- Нормалізація зазвичай приводить значення до діапазону від 0 до 1.
- Стандартизація перетворює дані відносно середнього значення та стандартного відхилення.
- K-Means залежить від масштабу ознак, оскільки використовує евклідову відстань.
- Перед застосуванням K-Means зазвичай варто масштабувати числові ознаки.
- Правильне масштабування допомагає отримувати більш обґрунтовані результати кластеризації.
