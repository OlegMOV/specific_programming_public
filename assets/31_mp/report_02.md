## 2. Основні поняття

**Кластеризація** — це метод машинного навчання, який об'єднує схожі об'єкти в групи.

**Кластер** — група об'єктів, які мають схожі характеристики.

**Схожість** — ступінь подібності об'єктів між собою.

**Відстань** — числова міра віддаленості між об'єктами.

**Центроїд** — центр кластера, який визначається за середніми значеннями координат його точок.

**Цільова функція** — математичний показник, який алгоритм намагається оптимізувати.

Кластеризація належить до навчання без учителя, оскільки правильні групи об'єктів заздалегідь не задані.

> [!NOTE]Кластеризація
Комп'ютер отримує зображення різних фруктів без назв і сам групує їх за схожістю: за кольором, формою та розміром.

> [!NOTE]Класифікація
Комп'ютер навчається на прикладах із відомими назвами фруктів, а потім визначає, чи є новий фрукт яблуком або апельсином.
## 3. Евклідова відстань

> [!TIP]
>  Кластеризація — комп'ютер сам шукає групи.
> 
>  Класифікація — комп'ютер визначає, до якого відомого класу належить об'єкт.


**Евклідова відстань використовується для визначення віддаленості між двома точками.**

Формула:

\[
$d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$
\]

Наприклад, для точок (1, 2) і (4, 6):

\[
$d=\sqrt{3^2+4^2}=\sqrt{25}=5$
\]

Отже, відстань між точками дорівнює 5.

## 4. Алгоритм K-Means

**K-Means** — алгоритм, який розподіляє дані на задану кількість кластерів.

Основні етапи роботи:

1. Задається кількість кластерів.
2. Визначаються початкові центри.
3. Кожна точка відноситься до найближчого центра.
4. Центри перераховуються за координатами точок.
5. Процес повторюється до стабілізації результату або до досягнення ліміту ітерацій.

Цільова функція K-Means:

\[
$J=\sum_{i=1}^{K}\sum_{x\in C_i}\|x-\mu_i\|^2$
\]

Алгоритм намагається мінімізувати суму квадратів відстаней від точок до центрів відповідних кластерів.

## 5. Практична реалізація на Python

Для виконання програми використовуються бібліотеки `scikit-learn` і `matplotlib`.

```python
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans

data = [
    [1, 2], [1.5, 1.8], [2, 1],
    [8, 8], [8.5, 8], [9, 9],
    [1, 8], [1.5, 9], [2, 8.5]
]

model = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

labels = model.fit_predict(data)
centers = model.cluster_centers_

print("Мітки кластерів:", labels)
print("Центри кластерів:")
print(centers)

plt.scatter(
    [p[0] for p in data],
    [p[1] for p in data],
    c=labels,
    cmap="viridis",
    s=100
)

plt.scatter(
    centers[:, 0],
    centers[:, 1],
    c="red",
    marker="X",
    s=200,
    label="Центри"
)

plt.title("Кластеризація методом K-Means")
plt.xlabel("X")
plt.ylabel("Y")
plt.legend()
plt.show()
```

### Пояснення коду

- `data` — набір координат точок.
- `KMeans()` — створення моделі кластеризації.
- `n_clusters=3` — кількість кластерів дорівнює трьом.
- `random_state=42` — забезпечує відтворюваність випадкової ініціалізації за однакових умов.
- `n_init=10` — кількість початкових запусків алгоритму.
- `fit_predict(data)` — навчання моделі та визначення кластерів.
- `cluster_centers_` — координати центрів кластерів.
- `plt.scatter()` — відображення точок на графіку.
- `plt.show()` — показ графіка.

## 6. Переваги та недоліки K-Means

**Переваги:**
- простий у використанні;
- швидко обробляє багато наборів даних;
- дає зрозумілий результат.

**Недоліки:**
- кількість кластерів потрібно задавати заздалегідь;
- результат залежить від початкових центрів;
- алгоритм чутливий до викидів;
- різний масштаб ознак може впливати на результат.
