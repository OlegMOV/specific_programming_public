2. Кластеризація даних. Підходи до кластеризації даних

Теорія - 65 хв, практика - 0 хв

На попередніх заняттях був розглянуті підходи до обробки даних на основі методів машинного навчання з учителем (supervised machine learning). Такі підходи передбачали наявність розмічених даних (labeled data), на основі яких проходило навчання моделей. Це були завдання регресії (regression) та класифікації (classification). Маючи натреновані моделі є можливість прогнозувати розвиток процесу, що досліджується.

якщо процес безперервний - регресія, якщо дискретний - класифікація

Методи машинного навчання без учителя (unsupervised machine learning) - передбачають наявність нерозмічених даних (unlabeled). І вже на їх основі формування гіпотез щодо наявних закономірностей між окремими значеннями набору даних, поєднуючи їх у кластери або виділяючи найбільш вагомі компоненти.

Для unsupervised machine learning завдання щодо обробки даних будуть розглядатися у двох аспектах:

  • *кластеризація (clustering)*
  • *зменшення розмірності простору ознак (feature dimension reduction)*.

У завданнях із кластеризації процес будується на основі знаходження цільової змінної на основі наявних даних. Це реалізується шляхом формування кластерів даних. У завданнях зменшення розмірності ознак - шляхом поєднання даних.

Для методів unsupervised machine learning застосовуються інші метрики при оцінюванні якості отриманої моделі. Причина - відсутність відомостей, які описують вірні рішення.

Кластеризація (clustering) — це метод аналізу даних, який використовується для групування об’єктів у набори (кластери) на основі їх схожості. Основна мета — знайти природні структури в даних без використання попередньо визначених міток.

2.1 Основні поняття кластеризації

При роботі із нерозміченими даними та пошуку публікацій за цією тематикою, можливо зустріти такі поняття:

  • Кластер: Група об’єктів, які мають подібні характеристики.
  • Схожість: Міра, що визначає, наскільки два об’єкти близькі один до одного (наприклад, евклідова відстань, косинусна схожість).
  • Відстань: Метрика, яка використовується для оцінки різниці між об’єктами (наприклад, манхеттенська, евклідова, Мінковського).
  • Типи даних для кластеризації:
    • Числові (наприклад, координати, вимірювання).
    • Категоріальні (наприклад, типи об'єктів).
    • Текстові.
    • Змішані.

2.2 Основні підходи до кластеризації

Існує кілька основних підходів до кластеризації, які можна поділити на категорії залежно від їхньої логіки та методології.

2.2.1 Розділові методи (Partitioning Methods)

Ці методи ділять набір даних на заздалегідь визначену кількість кластерів.

  • K-Means:
    Алгоритм розбиває дані на ( k ) кластерів, мінімізуючи суму квадратів відстаней від точок до центроїдів кластерів.
    • Переваги: Простота, швидкість, ефективність для великих наборів даних.
    • Недоліки: Потребує визначення ( k ), чутливий до початкових центроїдів, погано працює з некруглими кластерами.
  • K-Medoids (PAM):
    Схожий на K-Means, але використовує реальні об’єкти як центри кластерів (медоїди).
    • Переваги: Менш чутливий до викидів.
    • Недоліки: Вимагає більше обчислень.
2.2.2 Ієрархічні

Ці методи будують ієрархію кластерів, яка може бути представлена у вигляді дендрограми.

  • Агломеративна кластеризація (Bottom-Up):
    Починається з окремих об’єктів, які поступово об’єднуються в кластери на основі міри схожості.
    • Методи об’єднання: single linkage, complete linkage, average linkage, Ward’s method.
    • Переваги: Не потребує визначення ( k ), дозволяє бачити структуру даних.
    • Недоліки: Висока обчислювальна складність для великих наборів даних.
  • Дивізійна кластеризація (Top-Down):
    Починається з одного кластера, який поступово ділиться на менші.
    • Переваги: Корисно для виявлення вкладених кластерів.
    • Недоліки: Менш популярна, ніж агломеративна.
2.2.3 Щільнісні методи (Density-Based Methods)

Ці методи групують об’єкти на основі щільності точок у просторі.

  • DBSCAN (Density-Based Spatial Clustering of Applications with Noise):
    Виявляє кластери як області високої щільності, відокремлені областями низької щільності.
    • Переваги: Виявляє кластери довільної форми, автоматично визначає викиди.
    • Недоліки: Чутливий до параметрів (радіус околу, мінімальна кількість точок).
    • Застосування: Аналіз геопросторових даних, виявлення аномалій.
  • OPTICS:
    Розширення DBSCAN, яке створює ієрархію кластерів.
    • Переваги: Краще працює з даними змінної щільності.
2.2.4. Сіткові методи (Grid-Based Methods)

Ці методи ділять простір даних на сітку і кластеризують на основі комірок.

  • STING (Statistical Information Grid):
    Використовує сіткову структуру для зберігання статистичної інформації про дані.
    • Переваги: Швидка обробка великих наборів даних.
    • Недоліки: Менш точний для складних структур даних.
2.2.5. Модельні методи (Model-Based Methods)

Ці методи припускають, що дані генеруються певною статистичною моделлю.

  • Гауссові суміші (Gaussian Mixture Models, GMM):
    Використовує ймовірнісний підхід для моделювання кластерів як суміші нормальних розподілів.
    • Переваги: Гнучкість, враховує невизначеність приналежності до кластера.
    • Недоліки: Вимагає оцінки параметрів моделі.
2.2.6. Спектральна кластеризація

Використовує власні значення матриці схожості для зменшення розмірності перед кластеризацією.

  • Переваги: Ефективна для складних структур даних, таких як графи.
  • Недоліки: Висока обчислювальна складність.
2.2.7. Інші методи
  • Fuzzy C-Means: Дозволяє об’єктам належати до кількох кластерів із різними ймовірностями.
  • Самоорганізаційні карти Кохонена (SOM): Використовуються для кластеризації та зменшення розмірності.
  • Кластеризація на основі графів: Наприклад, алгоритми, що базуються на теорії графів, такі як spectral clustering або affinity propagation.

2.3 Практичні аспекти кластеризації

  • Вибір кількості кластерів:
    • Метод ліктя (Elbow Method).
    • Силуетний коефіцієнт (Silhouette Score).
    • Індекс Девіса-Боулдіна.
  • Масштабування даних:
    Нормалізація або стандартизація даних для коректної роботи алгоритмів (особливо для K-Means).
  • Оцінка якості кластеризації:
    • Внутрішні метрики: компактність кластерів, відокремленість.
    • Зовнішні метрики: порівняння з відомими мітками (якщо є).
  • Вибір метрики відстані:
    • Евклідова відстань для числових даних.
    • Косинусна схожість для текстових даних.
    • Відстань Хеммінга для категоріальних даних.

2.4 Сфери застосування кластеризації

  • Обробка зображень: Сегментація зображень, стиснення даних.
  • Аналіз соціальних мереж: Виявлення спільнот, аналіз взаємодій.
  • Рекомендаційні системи: Системи підтримки та прийняття рішень.

2.5. Виклики та обмеження

  • Вибір правильного алгоритму залежить від структури даних.
  • Чутливість до викидів та шуму.
  • Обчислювальна складність для великих наборів даних.
  • Проблема визначення оптимальної кількості кластерів.
  • Складність інтерпретації результатів у високовимірних даних.

Висновки

Кластеризація є потужним інструментом для аналізу даних, який дозволяє знаходити приховані структури в даних. Вибір підходу залежить від типу даних, мети аналізу та обчислювальних ресурсів. Важливо правильно налаштувати параметри та оцінити якість кластеризації, щоб отримати позитивні результати.
