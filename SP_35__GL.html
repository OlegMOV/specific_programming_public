1. Теоретичні основи методу K-means

Теорія - 40 хв, практика - 0 хв

Кластеризація, у контексті вивчення дисципліни, дозволяє знаходити у масиві даних (ознак), що описують об'єкти, схожі між собою (об'єкти) та об'єднувати їх у кластери.
Для об'єктів із двома ознаками таку операцію можна здійснювати та оцінювати результат візуалізувавши її (рис. 1.1-1.2). Для більшої кількості ознак таке завдання вже не може бути реалізовано у такий спосіб.

З вищенаведених двовимірних даних можливо зробити наступні висновки:

  • відсутність попередніх оцінок (labeled data) не дає змоги оцінити вірність прийнятих рішень щодо кількості кластерів та відношень точок до них
  • належність до кластеру ухвалюється на основі оцінювання відстані між ознаками
  • кластеризація - бачиться як процес пошуку цільової функції (процес: визначити кількість кластерів  ⇒ сформувати кластери  ⇒ оцінити якість проведеної роботи по першим двом крокам)

Алгоритм k-means передбачає виконання наступних умов:

  • кожний об'єкт, який оцінюється, має належати до одного із кластерів
  • кожен об'єкт може належати лише одному кластеру
об'єкт - сукупність ознак (features)

1.1 Суть алгоритму k-means

Алгоритм методу k-means наступний:

  1. обираємо кількість кластерів - k
  2. випадковим чином обираємо із усієї сукупності k об'єктів
  3. формуємо кластери на основі стратегії: найближчі об'єкти до обраних у попередньому пункті, належать до цього кластеру
  4. обчислюємо геометричні центри (точку) отриманих кластерів
  5. знаходимо найближчі об'єкти до цих геометричних центрів та формуємо із них кластер
  6. повторюємо кроки 4 та 5 доки кластери стануть незмінними

2. Підходи до вибору кількості кластерів

Теорія - 20 хв, практика - 0 хв

Вибір кластерів є важливим етапом розрахунку. Залежить від предметної області у якій проводиться дослідження.
Основними методами для такого завдання є:

  • метод ліктя (elbow method)
  • метод силуетів (silhouette method)

2.1 Метод ліктя / elbow method

Полягає у розрахунку суми відстаней від точок до геометричних центрів кластерів. Для того щоб посилити чутливість для більших відстаней, як правило застосовується сума квадратів таких відстаней (SSD - sum of squared distances).
У подальшому йде дослідження залежності знайденої, вищезазначеним чином, суми від кількості кластерів.
Прийнятним рішенням має бути кількість кластерів, коли збільшення їх кількості на одиницю не приводить до значного зменшення суми квадратів відхилень. На графіку це має вигляд більш пологого переходу.

Сума квадратів буде зменшуватися весь час аж до нуля. Тому потрібно обрати самостійно на основі міркувань про предмет досліджень.

Рис.1.3

Із наведеного рисунку видно, що при 5 кластерах зменшення сумарного відхилення уповільнюється. Тому є привід вважати, що **5 кластерів є оптимальним рішенням** для даного набору даних. Для того щоб отримати такий графік було застосовано наступний код:
  • проведення обчислень суми квадратів відхилень для кожного кластеру: 
import pandas as pd
from sklearn.cluster import KMeans

results = []
df = pd.read_csv('data_352.csv')

for i in range(1, 11):
    kmeans = KMeans(n_clusters=i, init='k-means++', 
	    max_iter=300, n_init=10, random_state=0)
    kmeans.fit(df[['ammunition', 'efficiency (1-100)']])
    results.append(kmeans.inertia_)
  • візуалізація величини відхилення для відповідної кількості кластерів: 
import matplotlib.pyplot as plt

plt.plot(range(1, 11), results)
plt.title('Метод ліктя')  
plt.xlabel('к-ть кластерів')
plt.ylabel('Відхилення')
plt.grid(True)
plt.show()

2.2 Метод силуетів / silhouette method

Суть такого підходу у розрахунку метрики, яка полягає у наступному:

де a - середня відстань у середині кластера;
b - відстань до найближчого кластера.

Розрахунок такої метрики здійснюється у декілька етапів. На початку обчислюється для кожної точки, потім для кожного кластеру розраховується середнє значення, після чого для всіх кластерів обчислюється загальне середнє значення.

Значення даної метрики знаходиться у діапазоні [-1;+1]

За результатами обчислень можна зробити висновки виходячи із наступного:

  • результат ближче до одиниці - кластери компактні та мають достатню дистанцію між собою
  • біля нуля - кластери не є компактними та границі не виразні
  • ближче до мінус одиниці - кластери накладаються один на одного

Для проведення пошуку кількості кластерів застосовується також відповідні інструменти із бібліотеки sklearn, а саме: 

from sklearn.metrics import silhouette_score

s_score = []

for i in range(2, 11):
    kmeans = KMeans(n_clusters=i, init='k-means++', max_iter=300, n_init=10, random_state=0)
    y_kmeans = kmeans.fit_predict(df[['ammunition', 'efficiency (1-100)']])
    score = silhouette_score(df[['ammunition', 'efficiency (1-100)']], y_kmeans)
    s_score.append(score)
