Регулярні вирази (RegExp - regular expression) є потужним інструментом, який дозволяє створювати гнучкі шаблони для пошуку екземплярів об'єктів типу str.
Цей механізм застосовується у багатьох мовах програмування та має схожі правила реалізації. Суть такого підходу полягає у застосуванні спеціальних символів, які у собі уособлюють цілий набір символів. Наприклад, \w - це шаблон для літери / цифри / [a-zA-Z0-9], \d - це шаблон для цифри [0-9]. Комбінуючи такі символи є можливість створювати складні шаблони для пошуку. Для розуміння значення спеціальних символів є зведена таблиця.

Розглянемо правила створення та застосування пошукових шаблонів у контексті регулярних виразів.

Для написання регулярних виразів використовуються метасимволи.
Метасимволи — це символи, що інтерпретуються особливим чином у механізмі регулярного виразу. Список метасимволів у Python: [] . ^ $ * + ? {} () \ |.

Метасимвол [] (квадратні дужки)
Квадратні дужки [] визначають набір символів для пошуку відповідності.

Шаблон Рядок Відповідає?
[abc] a 1 відповідність
[abc] ac 2 відповідності
[abc] Hey Jude Немає відповідностей
[abc] abc de ca 5 відповідностей

Тут [abc] буде відповідати рядку, який містить символи a, b або c

Ми також можемо визначити діапазон символів, використовуючи - всередині квадратних дужок, наприклад:

  • [a-e] те саме, що [abcde];
  • [1-4] те саме, що [1234];
  • [0-39] те саме, що [01239].

Ми також можемо інвертувати набір символів, використовуючи ^ після відкриття квадратної дужки, наприклад:

  • abc — означає будь-який символ, окрім a або b або c;
  • 0-9 — означає будь-який символ, який не є цифрою.

Метасимвол . (крапка)
Крапка . відповідає будь-якому одинарному символу (крім символу нового рядка '\n').

Шаблон Рядок Відповідає?
.. a Немає відповідностей
.. ac 1 відповідність
.. acd 1 відповідність
.. acde 2 відповідності (2 пари по 2 символи)
Метасимвол значення
^ - використовується для перевірки того, чи починається рядок з певного символу.
$ - використовується для перевірки того, чи закінчується рядок певним символом.
* - відповідає нулю або більше входжень решти шаблона.
+ - відповідає одному або більше входженням решти шаблона.
? - відповідає нулю або одному входженню решти шаблона.
{} - розглянемо наступний шаблон: {n,m}. Це означає діапазон — як мінімум n і як максимум m повторень шаблону.
\| - використовується для чергування (оператор or).
() - використовуються для створення підшаблонів. Наприклад, (a

Крім роботи із рядками, як елементами об'єкта Series, є можливість агрегувати дані, шляхом поєднання таких елементів. Для цього використовують метод .cat(). Слід пам'ятати, що об'єкт DataFrame складається із об'єктів Series, для яких можна застосовувати методи із бібліотеки NumPy.

import pandas as pd

s = pd.Series(["a", "b", "c", "d"], dtype="string")
s

0    a
1    b
2    c
3    d
dtype: string

s.str.cat()

'abcd'

s.str.cat(sep=' - ')

'a - b - c - d'

На практиці можуть зустрічатися випадки відсутності даних у чарунці. За замовчуванням відсутні дані ігноруються. Але при необхідності, на їх місце можливо помістити будь-яке значення, використавши для цього аргумент методу .cat(na_rep='--').

import numpy as np

t = pd.Series(["a", "b", np.nan, "d"], dtype="string")
t

0       a
1       b
2    <NA>
3       d
dtype: string

t.str.cat(sep=' -- ', na_rep='XX')

'a -- b -- XX -- d'

Для поєднання кількох стовпців використовують метод .concat(). Даний метод дозволяє поєднувати два і більше об'єктів Series в один, або створювати двовимірний масив DataFrame.

# об'єднання стовпців в один

# створення рядка з чисел

# створення рядка з символів
r2 = pd.Series([chr(100+x).upper() for x in range(5)])

pd.concat([r1, r2])
