1. Структура веб-сторінки

Теорія - 10 хв, практика - 15 хв

🎯Веб-сторінка — це окремий документ у форматі HTML, який відображається в браузері.

🎯HTML (англ. HyperText Markup Language — мова розмітки гіпертексту) — стандартизована мова розмітки документів для перегляду веб-сторінок у браузері
Основні теги:

  • <!DOCTYPE html> — вказує тип документа
  • <html> — кореневий елемент
  • <head> — службова інформація (метадані, підключення стилів, заголовок)
  • <title> — заголовок сторінки (відображається на вкладці)
  • <body> — основний вміст сторінки
🧩 Приклад базової структури:
<!DOCTYPE html>
<html>
  <head>
    <title>Моя перша сторінка</title>
  </head>
  <body>
    Вітаю на моїй сторінці!
  </body>
</html>

🧠Практичне завдання 1

  1. Розробити код для веб-сторінки відомої особистості, що містить поля:
    • ім'я та прізвище (використати теги div та span)
    • місце народження та дата (використати теги div та span)
    • чим відома дана особистість, кілька пунктів (використати теги ul та li)
  2. Додати класи та застосувати кольори до тексту та дат.

3. CSS таблиці стилів

Теорія - 10 хв, практика - 20 хв

Способи підключення:

  • Вбудований (<style>...</style> у <head>)
  • Зовнішній файл (<link rel="stylesheet" href="style.css">)
  • Inline-стилі (через атрибут style)
🧩 Приклад підключення CSS:

Зовнішній CSS-файл
Створіть файл style.css:

body {
  background: #e0f7fa;
}
h1 {
  color: #00796b;
}

Підключіть у HTML:

<head>
  <link rel="stylesheet" href="style.css" />
</head>

Вбудовані стилі

<head>
  <style>
    p {
      color: blue;
    }
  </style>
</head>

Інлайн-стилі

<p style="color: green; font-weight: bold;">Текст із інлайн-стилем</p>
🔑 Основні властивості:**
  • color — колір тексту
  • background — фон
  • font-size — розмір шрифту
  • margin, padding — зовнішні/внутрішні відступи
  • border — рамка

4. Використання класів у CSS

Теорія - 10 хв, практика - 25 хв

🎯 Клас — це спеціальний атрибут (class), який дозволяє застосовувати стилі до групи елементів.

Вони дозволяють уникати дублювання коду та роблять оформлення більш гнучким і структурованим.

Як працюють класи:
  • У HTML клас задається атрибутом class: 
    <p class="highlight">Цей текст виділений.</p>
  • У CSS клас описується через крапку .: 
    .highlight {
  color: red;
  font-weight: bold;
}
🔑 Основні можливості:
  • Можна застосовувати до багатьох елементів: один клас може використовуватися в різних місцях сторінки.
  • Можна комбінувати: елемент може мати кілька класів одночасно.
  • Гнучкість: класи зручно використовувати для повторюваних стилів (наприклад, кнопки, блоки, заголовки).
🧩 Приклад
<!DOCTYPE html>
<html>
<head>
  <style>
    .button {
      padding: 10px 20px;
      border-radius: 5px;
      cursor: pointer;
    }
    .primary {
      background-color: blue;
      color: white;
    }
    .secondary {
      background-color: gray;
      color: black;
    }
  </style>
</head>
<body>
  <button class="button primary">Основна кнопка</button>
  <button class="button secondary">Додаткова кнопка</button>
</body>
</html>
📌 Пояснення
  • Клас .button задає базовий стиль для всіх кнопок.
  • Класи .primary та .secondary додають різні кольори.
  • Завдяки цьому можна легко створювати кнопки різних типів, не дублюючи код.

Класи — це інструмент повторного використання стилів, який робить дизайн масштабованим і акуратним.

Як правило, файли із сервера, із яких складається веб-сторінка, передаються окремими файлами - з html-тегами, css стилями, та JS.

Веб-сторінка, як правило має посилання на інші ресурси мережі. Для цього застосовується тег a. Його синтаксис наступний

🧩 Приклад
<!DOCTYPE html>
<html>
<head>
 
</head>
<body>
<ul>
	<li><a href='https://en.wikipedia.org/wiki/Ukraine'>Про Україну</a></li>
	<li><a href='https://en.wikipedia.org/wiki/Eastern_Europe'>Про Східну Європу</a></li>
	<li><a href='https://en.wikipedia.org/wiki/Southeast_Europe'>Про Південно-східну Європу</a></li>

🔑 Типові помилки
  • Плутанина між .class і #id — клас використовується для багатьох елементів, id — лише для одного.
  • Занадто загальні селектори можуть неочікувано впливати на багато елементів.
  • Відсутність специфічності: якщо селектор занадто простий, його можуть "перебити" інші стилі.
  • Використання однакових id для кількох елементів — це помилка.

  3. Оформити сторінку за допомогою CSS (змінити кольори, відступи, шрифти).

5. CSS-селектори

Теорія - 15 хв, практика - 30 хв

🎯 CSS-селектори — це правила, за якими вибираються HTML-елементи для стилізації. Вони дозволяють застосовувати стилі лише до тих елементів, які відповідають певним умовам.

Завдяки селекторам можна гнучко керувати виглядом сторінки, не змінюючи сам HTML-код.

Базові селектори

🎯Селектор тегу — вибирає всі елементи певного типу (наприклад, всі <p>, <h1>, <a> тощо)

p {
  color: red;
}
📌 Пояснення:

Всі абзаци стануть червоними.

🎯Селектор класу — вибирає елементи з певним класом.

Клас може бути призначений багатьом елементам:

.menu {
  font-weight: bold;
}
📌 Пояснення:

Всі елементи з class="menu" стануть жирними.

Селектор ідентифікатора — вибирає елемент з певним id. Id має бути унікальним на сторінці:

#header {
  background: yellow;
}
📌 Пояснення:

Елемент з id="header" отримає жовтий фон.

Комбіновані селектори

🎯 Селектор нащадка (пробіл) — вибирає всі <p> всередині <div> (на будь-якій глибині):

div p {
  color: blue;
}
📌 Пояснення:

Всі абзаци всередині div стануть синіми.

🎯Селектор дочірнього елемента (>) — вибирає лише безпосередніх дітей:

ul > li {
  list-style: square;
}
📌 Пояснення:

Тільки ті <li>, які є прямими дітьми <ul>.

🎯 Сусідній селектор (+) — вибирає елемент, який йде одразу після іншого:

h2 + p {
  margin-top: 0;
}
📌 Пояснення:

Перший <p> після <h2> не матиме відступу зверху.

🎯Загальний сусідній селектор (~) — вибирає всі елементи, які знаходяться на одному рівні після заданого:

h2 ~ p {
  color: green;
}
📌 Пояснення:

Всі <p> після <h2> на одному рівні вкладеності стануть зеленими.

🧠Практичне завдання 5

  1. Створити HTML-файл із наступною структурою:
    <div id="header">Заголовок сайту</div>
    <div>
    <h2>Підзаголовок</h2>
    <p>Перший абзац після h2</p>
    <p>Другий абзац після h2</p>
    <ul>
    <li>Пункт 1</li>
    <li>Пункт 2</li>
    </ul>
    </div>
  2. Додати CSS-стилі, використовуючи вищенаведені селектори:
  • Зробити фон елемента з id="header" жовтим.
  • Змінити колір тексту всіх <p> всередині <div> на синій.
  • Для <li>, які є прямими дітьми <ul>, встановити квадратні маркери.
  • Перший <p> після <h2> зробити без верхнього відступу.
  • Всі <p>, які йдуть після <h2> (на одному рівні), зробити зеленими.
  1. Перевірити отриманий результат у браузері.

Атрибутні селектори

[attribute] — вибирає елементи, які мають певний атрибут:

a[target] {
  color: orange;
}
📌 Пояснення:

Всі посилання з атрибутом target стануть оранжевими.

[attribute="value"] — вибирає елементи з точним значенням атрибута:

input[type="text"] {
  border: 1px solid;
}
📌 Пояснення:

Всі текстові поля вводу матимуть рамку.
[attribute^="val"] — значення починається з "val".
[attribute$="val"] — значення закінчується на "val".
[attribute*="val"] — значення містить "val".

🧩 Приклад
a[href^="https"] {
  color: green;
}
a[href$=".pdf"] {
  color: red;
}
a[href*="example"] {
  font-style: italic;
}

🧠Практичне завдання 6

  1. Створити HTML-файл із наступними елементами:
    <a href="https://example.com" target="_blank">Зовнішнє посилання</a>
    <a href="file.pdf">PDF файл</a>
    <a href="https://test.com">Інше посилання</a>
    <a href="https://myexample.org">Ще одне посилання</a>
    <input type="text" placeholder="Введіть текст" />
    <input type="password" placeholder="Пароль" />
  2. Додати CSS-стилі, використовуючи атрибутні селектори:
  • Зробити усі посилання з атрибутом target оранжевими.
  • Для <input type="text"> додати чорну рамку.
  • Посилання, що починаються з https, зробити зеленими.
  • Посилання, що закінчуються на .pdf, зробити червоними.
  • Посилання, у яких href містить "example", зробити курсивними.
  1. Перевірити результат у браузері.

Псевдокласи

:hover — елемент при наведенні курсора.
:active — елемент у момент натискання.
:focus — елемент у фокусі (наприклад, поле вводу).
:first-child — перший дочірній елемент у батьківському.
:last-child — останній дочірній елемент.
:nth-child(n) — n-й елемент серед братів.

🧩 Приклад
a:hover {
  text-decoration: underline;
}
input:focus {
  border-color: blue;
}
li:first-child {
  color: red;
}
li:nth-child(2n) {
  background: #eee;
}
📌 Пояснення:

Можна створювати "зебру" для таблиць чи списків.

Псевдоелементи

::before — додає контент перед вмістом елемента.
::after — додає контент після вмісту елемента.
::first-line — стилізує перший рядок тексту.
::first-letter — стилізує першу літеру.

🧩 Приклад
p::first-line {
  font-weight: bold;
}
p::first-letter {
  font-size: 200%;
  color: orange;
}
div::after {
  content: "✔";
  color: green;
}

Псевдоелементи часто використовують для декоративних ефектів.

  2. Додати CSS-стилі:

  • Для абзацу виділити перший рядок жирним, а першу літеру — великою та помаранчевою.
