1. Бібліотека BeautifulSoup

Теорія - 20 хв, практика - 20 хв

🎯BeautifulSoup - бібліотека, що дозволяє завантажувати дані із HTML / XML документів.
Суть її роботи є не складною, але дозволяє заощадити багато часу якщо потрібно забезпечити роботу щодо пошуку та редагування документів такого типу.
Встановлення бібліотеки

pip install beautifulsoup4

Робота з бібліотекою передбачає наявність HTML / XML документу. Для цього, як правило застосовують бібліотеку requests.
Для ініціалізації об'єкту BeautifulSoup передається текст документа та обирається модуль, який буде здійснювати аналіз html-документу (парсер).

from bs4 import BeautifulSoup

with open("index.html") as fp:
    soup = BeautifulSoup(fp, 'html.parser')

Як правило, робота із бібліотекою має наступний вигляд

import requests
from bs4 import BeautifulSoup

URL = ""

resp = requests(URL)
bs = BeautifulSoup(resp.content, "html.parser")

Змінна bs є об'єктом bs4.BeautifulSoup, методи якого забезпечують доступ до елементів структури html-документу.

from bs4.element import NavigableString
def removeNavStrings(blockTags):
    return list(filter(lambda x: type(x) != NavigableString, blockTags))

1.2. Отримання тексту

Для отримання тексту із тегів застосовуються наступні методи:

  • get_text()
  • text
  • string
text = ex_bs.ul.get_text()
text

'\nItem 1\nItem 2\nItem 3\n'

ex_bs.ul.text

'\nItem 1\nItem 2\nItem 3\n'

ex_bs.ul.string # None, оскільки є вкладені теги

Для видалення символу нового рядку можна використати атрибут методу .get_text(strip: Boolean)

ex_bs.ul.get_text(strip=True)

'Item 1Item 2Item 3'

Для більш очевидного розділення елементів додамо розділювач

ex_bs.ul.get_text(separator=' / ', strip=True)

'Item 1 / Item 2 / Item 3'

Ще одним підходом для отримання усіх рядків із створеного документу є застосування атрибуту .stripped_strings, що повертає генератор

strings_list = list(ex_bs.stripped_strings)
strings_list

['Item 1', 'Item 2', 'Item 3']

Усі проведені операції дозволяють створити окрему функцію для обробки блоку html-сторінки для отримання даних про статтю

def parse_news_item(item):
    title_tag = item.find("a", attrs={"class":'list-thumbs__title'})
    title = title_tag.get_text(strip=True) if title_tag else "No Title"
    link = title_tag['href'] if title_tag else "No Link"
    time_tag = item.find("div", attrs={"class":'list-thumbs__time'})
    date_str = time_tag.get_text(strip=True) if time_tag else "00:00, 01.01.1970"
    date_obj = datetime.strptime(date_str, "%H:%M, %d.%m.%Y")
    return {
        "title": title,
        "link": link,
        "date": date_obj
    }
